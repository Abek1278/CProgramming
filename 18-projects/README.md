# Practical C Projects

This directory will house complete, standalone C projects developed as I progress through the curriculum.

---

## 🎯 Learning Roadmap & Planned Projects

As concepts are mastered, projects will be built here following the learning philosophy:
> *Learn the concept → Write the code → Break the code → Fix it → Build something with it.*

| Project | Key Concepts Applied | Status |
| :--- | :--- | :--- |
| **CLI Calculator** | Operators, Functions, Switch-case, Input validation | ⏳ Planned |
| **Number Guessing Game** | Loops, Conditionals, Pseudo-random numbers (`rand()`), Game loop | ⏳ Planned |
| **Student Management System** | Structures, Dynamic Memory, Arrays of Structs, Sorting | ⏳ Planned |
| **Bank Management System** | Structs, Authentication simulation, Account balances, Modularity | ⏳ Planned |
| **File Handling System** | Persistent storage, CSV/text file parsing, Buffer safety | ⏳ Planned |
